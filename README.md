# Мәтіндік есептерді анимациялау

Мәтін түріндегі математика есептерін талдап, шешімін анимация арқылы
көрсететін бет. Бәрі бір ғана `index.html` файлында.

**Ашу:** https://ab1lkaiyr.github.io/matin_esep_animation/

## Есеп түрлері

- **Қозғалыс** — кездесу, қуып жету, қарама-қарсы бағыттағы қозғалыс
- **Бірлескен жұмыс** — құбырлар, сорғылар, жұмысшылар; ағызу құбырын қоса
- **Өзен ағысы** — ағыс бойымен, ағысқа қарсы, барып-қайту жолы

## Қалай жұмыс істейді

Есеп шартын ережелерге негізделген алгоритм талдайды: тұрақты өрнектер
өлшем бірлігі бар сандарды табады, сөздік — қатысушыларды, түйінді сөздер —
есеп түрін анықтайды. Іске қосылған әрбір ереже бетте көрсетіліп тұрады,
сондықтан шешімнің әр қадамы ашық.

Есеп шарты қазақ тілінде болуы керек.

Талдау, сандық есептеулер және анимация тікелей браузерде орындалады.
Интернетке қосылу қажет емес — бет офлайн режимде жұмыс істейді.
